MD 閱讀器

把 Markdown 檔變成好讀的排版

把 .md 檔拖曳到這裡
或
Ctrl + O
最近開啟

    小技巧：在 .md 檔按右鍵 →「開啟檔案」→「選擇其他應用程式」→ 選 MDViewer.exe 並勾「一律使用」，以後雙擊 .md 就會直接用這個打開。

    放開以開啟檔案

    鍵盤快捷鍵

    Ctrl + O開啟檔案
    Ctrl + F搜尋文字（Enter 下一個）
    Ctrl + B顯示／隱藏目錄
    Ctrl + P列印
    F5重新載入檔案
    Ctrl + + / − / 0放大／縮小／還原
    Alt + ←回上一份文件
    Home / End跳到最上／最下

    檔案存檔後會自動重新整理，不用手動重開。
